# Grilling

Invoke this skill only when the user explicitly asks for grilling.

Clarify the decision before acting. Explore facts available in the environment;
reserve questions for choices the user owns.

Ask one question at a time. Give a concise recommended answer and the cost that
could change the choice, then wait. Follow dependencies between decisions until
the plan has a shared, explicit understanding.

Do not implement the plan until the user separately authorizes implementation.

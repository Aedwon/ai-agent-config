# Decisions

Use one entry for each consequential choice.

## Decision entry

- Date: use an ISO 8601 calendar date
- Status: proposed, accepted, superseded, or rejected
- Context: state the problem and constraints
- Decision: state the chosen approach
- Alternatives: list viable options and rejection reasons
- Consequences: state costs, risks, and follow-up triggers
- Evidence: link the governing specification, plan, source, or test result

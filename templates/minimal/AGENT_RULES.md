# Project Agent Rules

The rendered entry combines this project layer with the universal core.

- Inspect relevant source and current state before describing or changing it.
- Keep changes within the requested project and preserve unrelated work.
- Obtain matching authority for edits, Git actions, destructive operations,
  publication, deployment, and external-system changes.
- Verify changed behavior with current evidence before claiming completion.
- Stop on contradictory instructions, stale governing state, or unclear
  mutation scope.

No external skill package or global configuration manager is required.

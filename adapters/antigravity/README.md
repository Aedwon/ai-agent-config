# Google Antigravity Adapter

Antigravity IDE stores workspace rules under `.agents/rules/`. This adapter
renders one workspace rule and does not add workflows, skills, global rules, or
global configuration.

Source reviewed August 25, 2026: [Getting Started with Antigravity
IDE](https://codelabs.developers.google.com/getting-started-agy-ide).

Render into staging and inspect the diff before copying the file into a
workspace. Activate the rule through the IDE when required. The template
changes no canonical policy semantics.

# Gemini CLI Adapter

Gemini CLI uses `GEMINI.md` as its default hierarchical project context file.
This adapter renders the root project entry only and does not change the
configurable context filename or global context.

Source updated June 18, 2026 and reviewed August 25, 2026: [Provide context with
GEMINI.md files](https://geminicli.com/docs/cli/gemini-md/).

Render into staging and inspect the diff before copying the file into a project.
The template changes no canonical policy semantics.

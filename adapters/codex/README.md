# Codex Adapter

Codex discovers `AGENTS.md` at project scope and layers files from the project
root toward the current directory. This adapter renders the root project entry
only; it does not create overrides or change global configuration.

Source reviewed August 25, 2026: [Custom instructions with
AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Render into staging and inspect the diff before copying the file into a project.
The template changes no canonical policy semantics.

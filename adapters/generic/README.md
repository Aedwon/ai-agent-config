# Generic Adapter

The generic adapter renders `AGENT_RULES.md` for manual integration. It makes no
automatic discovery claim because generic agents share no universal project or
global instruction filename.

Project and global scopes both use that relative filename beneath the explicit
staging or target root. Global scope contains only the universal core. The tool
never discovers a home directory or installs the result. Inspect the staged
file, then configure the target agent through its documented mechanism.

# Example Personal Profile

These values demonstrate the layer. They are not universal defaults.

- Keep routine status reports below 200 words.
- Use American spelling and direct sentences.
- For consequential work, present lean, standard, and assured options with a
  recommendation before implementation.
- Prefer local verification before remote services.
- Explain non-obvious architecture decisions in one or two sentences.
- Keep unrelated goals in separate tasks.

This profile changes presentation and process preferences only. It grants no
permission to edit, commit, publish, deploy, delete, or change an external
system.
